## 2. Поле "Логин"

**Требования:**
- Минимум 5 символов.
- Максимум 20 символов.
- Допускается ввод латиницы, кириллицы и спецсимволов: `_`, `-`, `@`.

| ID | Название | Предусловие | Шаги | Ожидаемый результат |
|---|---|---|---|---|
| TC-LOG-01 | Валидный логин (мин. 5 символов) | Страница открыта | Ввести "User1" | Поле принимает значение, ошибок нет |
| TC-LOG-02 | Валидный логин (макс. 20 символов) | Страница открыта | Ввести 20 символов | Поле принимает значение, ошибок нет |
| TC-LOG-03 | Логин меньше 5 символов | Страница открыта | Ввести "User" (4 символа) | Отображается ошибка валидации |
| TC-LOG-04 | Логин больше 20 символов | Страница открыта | Ввести 21 символ | Отображается ошибка валидации / ввод ограничен |
| TC-LOG-05 | Логин с латиницей | Страница открыта | Ввести "Login" | Поле принимает значение |
| TC-LOG-06 | Логин с кириллицей | Страница открыта | Ввести "Логин" | Поле принимает значение |
| TC-LOG-07 | Логин со спецсимволами `_`, `-`, `@` | Страница открыта | Ввести "user_name-1@test" | Поле принимает значение |
| TC-LOG-08 | Логин с недопустимыми спецсимволами | Страница открыта | Ввести "user#name" | Отображается ошибка валидации |
| TC-LOG-09 | Пустое поле "Логин" | Страница открыта | Оставить поле пустым | Отображается ошибка "Поле обязательно" |
| TC-LOG-10 | Логин с пробелами | Страница открыта | Ввести "user name" | Отображается ошибка валидации |

| TC-YER-04 | Ввод букв | Страница открыта | Ввести "abcd" | Отображается ошибка валидации |
| TC-YER-05 | Пустое поле "Год" | Страница открыта | Оставить поле пустым | Отображается ошибка "Поле обязательно" |
